## `03 / PROYECTOS DESTACADOS`

### [M-NMAP](https://github.com/gerardogonzalez0264gg/M-NMAP)

**Escáner de puertos TCP | Python**

Herramienta de análisis de puertos inspirada en Nmap. Incluye escaneo concurrente, identificación de servicios, captura de banners y diferentes niveles de velocidad.

### [SSH-HONEYPOT](https://github.com/gerardogonzalez0264gg/SSH-HONEYPOT)

**Honeypot SSH | Python**

Entorno SSH simulado para registrar intentos de autenticación, monitorear comandos y analizar actividad sospechosa.

### [ANALIZADOR DE LOGS](https://github.com/gerardogonzalez0264gg/Analizador-de-log)

**Análisis de registros | Python**

Herramienta para analizar registros de autenticación, identificar múltiples intentos fallidos de acceso y detectar direcciones IP sospechosas.
